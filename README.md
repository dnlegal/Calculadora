# Calculadora de combustível para Kwid

Aplicativo web simples para comparar os preços de gasolina e etanol e indicar qual vale mais a pena para abastecer.

## Como usar

1. Abra o arquivo `index.html` no navegador.
2. Informe o preço da gasolina e do etanol.
3. Clique em **Calcular** para ver a recomendação.

## Regra de cálculo

A calculadora usa a regra prática de 70%:

- Se o preço do etanol for até **70%** do preço da gasolina, etanol compensa.
- Caso contrário, gasolina compensa.
